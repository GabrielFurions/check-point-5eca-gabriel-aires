# GABRIEL PESSOA AIRES - RM88731 - 5ECR

## Funcionalidades

Este projeto ESP-IDF demonstra:
- Uso de semáforos binários para sincronização de tarefas FreeRTOS
- Leitura simulada de dados de PDF
- Exibição de dados em formato de tabela formatada

### Funcionalidade de Leitura de PDF e Exibição em Tabela

A Tarefa 1 demonstra a leitura de dados simulados de um PDF e sua exibição em uma tabela formatada no console:

**Nota:** Como este é um projeto embarcado ESP-IDF, a implementação simula a leitura de dados de PDF em vez de realizar análise real de PDF, o que seria impraticável para sistemas embarcados.
